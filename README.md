## GeoLens

[`geolens/`](geolens/) is a Windows GEOINT photo geolocation app. It uses StreetCLIP visual geolocation, OCR, EXIF metadata, sun/shadow analysis and key-less reverse image search (Yandex, Lens, Bing, TinEye), and has an explainable teaching log.
The `.exe` is built by the **Build GeoLens (Windows .exe)** GitHub Actions workflow.
